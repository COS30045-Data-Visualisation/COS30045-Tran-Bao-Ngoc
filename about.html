About Us

This site was built for Exercise 0.2 of COS30045 Data Visualisation at Swinburne University of Technology.

Purpose of this site

Placeholder content. The site demonstrates a small multipage website built with HTML, CSS and vanilla JavaScript, with the code kept in a GitHub repository. It is the starting point for the D3 work later in the unit, and the page structure here is reused in the Week 3 and Week 4 exercises.

What this site demonstrates

  • Three linked pages sharing one navigation bar and one stylesheet.
  • A logo that returns the visitor to the home page, with a hover effect.
  • A clear indication of which page is currently open.
  • An accordion FAQ that is hidden by default and controlled with JavaScript.
  • An interactive energy calculator written in vanilla JavaScript.
  • Styling kept entirely in an external stylesheet.

Technologies used

HTML

Provides the structure and content of the website.

CSS

Controls layout, colours and responsive design.

JavaScript

Provides the FAQ and calculator functionality.
